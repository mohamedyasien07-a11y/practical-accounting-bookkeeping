# Practical Accounting & Bookkeeping Project

## Project Overview
This project demonstrates practical accounting and bookkeeping procedures using Microsoft Excel. It covers the accounting cycle, from recording financial transactions to preparing financial statements.

## Project Objectives
- Practise double-entry bookkeeping.
- Record journal entries and post them to ledgers.
- Prepare and verify a trial balance.
- Prepare basic financial statements.
- Apply Excel formulas to accounting calculations.

## Workbook Contents

| Worksheet | Description |
|---|---|
| Journal Entries | Recording business transactions using debit and credit |
| Ledger | Posting transactions into individual accounts |
| Trial Balance | Checking debit and credit balances |
| Trading and Profit & Loss | Calculating gross loss and net loss |
| Balance Sheet | Presenting assets, equity and liabilities |
| Cash Flow Statement | Classifying operating, investing and financing activities |

## Tools Used
- Microsoft Excel
- Excel formulas
- Accounting and bookkeeping principles
- Double-entry bookkeeping

## Skills Demonstrated
- Journalising and ledger posting
- Account classification
- Trial balance preparation
- Financial statement preparation
- Cash flow classification

## Project Assumptions
This is a simplified educational practice project based on the transactions recorded in the workbook.
